The Plan Document Style

The exact design system used by every document in .plans/. This page is written in the system it describes — every rule below is also visible in use, on this page.

Palette: warm dark, 6 colors Type: Fraunces · Inter · JetBrains Mono Column: 880px Dependencies: Google Fonts + Prism (CDN)

01The palette

Six colors, all warm. The rule that makes it cohesive: no pure grays, no pure white, no pure black — every neutral leans brown, so the page feels like paper in lamplight rather than a terminal.

VariableValueRole
--bg#1B1A16Page background. Near-black with a warm brown cast.
--surface#24221CCards, tables, anything that sits "on" the page. Exactly one step lighter than the background, same hue.
--ink#EDEAE0Primary text. Warm off-white — never #fff, which would glare against the warm background.
--ink-soft#A5A195Secondary text: ledes, captions, table headers, metadata.
--accent#E08A5CTerracotta. Kickers, section numbers, links, emphasis. The identity color.
--accent-soft#3A2A20Terracotta at background strength, for callout fills.
--green#7FBF92Success, confirmation, "good" callouts.
--green-soft#22312AGreen at background strength.
--line#38352CEvery border and divider. One border color for the whole document.
The two-strength rule: each accent hue exists as a bright version (text, borders) and a "soft" dark version (fills). A callout is the bright hue as a 4px left border on the soft hue as background — same color, two strengths, which is why nothing ever clashes.

02Typography

Three faces, three jobs, no exceptions.

FaceJobRules
FrauncesDisplay: h1, h2 onlySerif with personality, weight 650. Title sized clamp(32px, 5vw, 46px), sections 27px. Never used for body text — scarcity is what keeps it special.
InterEverything readable16px body on line-height: 1.65; 17px ledes; 14.5px table text; weights 400–700.
JetBrains MonoEverything data-likeCode, numbers, section numerals, step counters, anything a monospace grid helps. 13.5px in blocks.

03Structural components

Each device encodes something — none are decoration.

Kicker (eyebrow)

The tiny uppercase label above the title, telling you what kind of document you're in. 12px · letter-spacing 0.14em · uppercase · var(--accent) · weight 700. You saw one at the top of this page.

Numbered section headings

An h2 is a flex row: a small mono accent number (01) sharing a baseline with the big serif title. The numbers say "this document has a reading order." This is the style's most recognizable move.

Header & footer rules

The document header closes with a heavy rule (2px solid var(--ink) — full contrast); the footer opens with a light one (1px var(--line)). Heavy at the top, light at the bottom: the page announces itself loudly and exits quietly.

Cards and callouts

Card: var(--surface) + 1px var(--line) border + 10px radius + 20px 24px padding. For grouped prose and specs.

Callout: 4px accent left border on --accent-soft, radius only on the right corners. For warnings and key decisions.
Good callout: same shape in green, for reassurances and verified facts.

Tables

Same shell as cards (overflow: hidden makes the radius clip the rows). Header row: slightly different background (#2A281F), 12.5px uppercase letterspaced --ink-soft. First column bolded and white-space: nowrap — it acts as the row's label.

Step lists

  1. Built with CSS counters No hand-numbering: counter-increment fills a 32px circle (--ink background, --bg mono digits) via ::before.
  2. Connected by a thread A 2px --line vertical connector drawn with ::after links each circle to the next — sequence made visible.

Pills

✓ in scope neutral tag ✗ out of scope

border-radius: 999px chips; the in/out variants encode scope decisions (green + check, struck-through + muted).

04Code & data

Code blocks are Prism with the tomorrow theme — its #2d2d2d background reads as another warm surface. Inline code gets its own chip.

// Block code: prism-tomorrow via cdnjs, 10px radius, 13.5px JetBrains Mono
const example = "self-demonstrating";

Inline code like --accent uses background: #2E2C24; padding: 2px 6px; border-radius: 5px. Numbers in prose that carry data weight are set in mono.

05Diagrams

Hand-written inline SVG, no libraries — and the same palette hexes as the CSS, which is what makes diagrams feel native to the page instead of pasted in.

Diagram rules: boxes are --surface fill with --ink stroke at 1.5px; arrows are --ink-soft with one shared <marker> arrowhead; semantic color (accent/green) marks meaning, not decoration; at most one inverted (light-filled) box per diagram as the focal point; labels are Inter, wire-format text is JetBrains Mono; every figure gets a figcaption.

Starting boilerplate

A new document needs the two CDN links and the CSS from any existing plan doc — the fastest start is copying password-gate.html and replacing the content. The head, exactly:

<link rel="icon" type="image/svg+xml" href="icon.svg">
<link href="https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,9..144,500;0,9..144,650;1,9..144,500&family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;600&display=swap" rel="stylesheet">
<link href="https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/themes/prism-tomorrow.min.css" rel="stylesheet">
<!-- before </body>: prism.min.js + one prism-<language>.min.js per language used -->
The whole identity in one sentence: warm browns instead of grays, a serif that only appears in headings, mono wherever there's data, one border color, one radius, and every accent color in exactly two strengths.
