03What changes in the code

Display order only — nothing in the database, the totals or the day grouping changes.

WhereTodayAfter
EatenToday.tsxRenders the day's meals as the server sends them (oldest first)Renders them reversed, newest first
LogList.tsxReverses the newest-first list so each day reads in eating orderKeeps the list newest first inside each day; days stay newest first
