A compiled map of unused Next.js — from this calorie app, older Pages-era APIs, and Next 16.3 — so you can pick experiments that actually teach something.

01Fits this calorie app

Things you could try here without a new repo. Best single lesson: Instant Navigations + 'use cache' on /log and /stats.

ThingWhy it fits
Instant Navigations + 'use cache'Tab switches would show nav + skeleton instantly. Enable cacheComponents and partialPrefetching. The Next 16.3 headline.
'use cache' + cacheLife / cacheTagGoals and today’s totals change rarely. Cache them; invalidate on save.
updateTag / revalidateTag / refresh()Finer than blanket revalidatePath. updateTag = read-your-writes; revalidateTag(tag, 'max') = stale-while-revalidate; refresh() = uncached data.
View TransitionsFour-tab TopNav. Fade pages or shared-element the calorie number in TodayStrip.
useOptimisticLogList / ProductList already wait, then toast undo. Make delete/edit instant.
Intercepting routesTurn ImageLightbox into /log/photo/[id]: in-app modal, refresh = full page.
after()You already persist barcode products after a log. Finish that work after the success response.
Explicit <Suspense>Stream TodayStrip separately from the heavy Analyze UI, not only via loading.tsx.
error.tsx / global-error.tsx/log, /products, /stats already have inline try/catch banners.
not-found.tsx + notFound()Custom 404 if you add deep links.
generateMetadata per routeDistinct PWA tab titles for Log / Stats / Products.
Form actions + useFormStatusOnly login uses <form action>. CRUD as progressive-enhancement forms.
robots.ts (disallow all)Password gate is not a crawler block.
Security headersCSP / frame protections in next.config.ts for a deployed PWA.
Skip on this app: next/image (photos are blob/data URLs) and parallel routes for tab state (AnalysisProvider already keeps Analyze alive across tabs).

02Weekend toys

New repo, throw it away if ugly. High fun per hour.

  1. Intercepting + parallel routes — Instagram pattern. Click photo → modal + URL change; refresh → full page. The most Next-specific routing trick.
  2. next/og (ImageResponse) — Ticket, recap, or share card as JSX → PNG.
  3. Tiny MDX blog — generateStaticParams, MDX in /content, custom h2. Classic for a reason.
  4. View Transitions gallery — Shared-element thumbnail → detail.
  5. Streaming UI / AI chat — Tokens into the page via Suspense / ReadableStream, not “wait for JSON then setState.”
  6. next/image playground — remotePatterns, blur placeholder, priority, fill + art direction.
  7. next/form — Progressive enhancement: the form works before JS hydrates.
  8. next/script — beforeInteractive / afterInteractive / lazyOnload for a third-party widget.
One-project combo: a 12-photo gallery — intercepting modal + next/image + blur + next/og per photo + View Transitions. Four Next skills you have barely touched.

03Career Next

Features interviewers and old codebases still assume. Half of real Next in the wild is still Pages Router.

ThingWhat you learn
Pages Router on purposegetStaticProps, getServerSideProps, getStaticPaths, _app, _document. The contrast teaches why RSC exists.
ISRrevalidate: 60, change content, watch regeneration. Mental ancestor of 'use cache' + cacheLife.
Draft Mode + CMSSanity / Contentful / markdown. Preview unpublished pages via a cookie. Does not work with output: 'export'.
i18n[locale] segment + next-intl. App Router has no i18n config key — that is Pages-only.
Proxy rewritesGeo greeting, A/B cookie, /blog → /posts. You have a password proxy; this is the other half.
generateStaticParams + dynamicParamsPrebuild /posts/[slug]; 404 or on-demand for the rest.
Catch-all routes[...slug] and [[...slug]] for docs sites.
Route groups + multiple roots(marketing) vs (app) with different <html> chrome.
template.tsxLike a layout, but remounts every navigation (enter animations, reset state).
forbidden() / unauthorized()Next 15+ auth interrupts (experimental.authInterrupts). 403 / 401 files, same idea as notFound().
Taint APIsexperimental.taint + taintObjectReference / taintUniqueValue. Stop leaking tokens across the RSC boundary.
server-only / client-onlyCompiler errors if a secret helper is imported on the wrong side.
Career combo: a tiny MDX blog with ISR and Draft Mode. That is the feature set people still assume you know.

04Caching and data, old → new

The story Next has been telling for four years, in one place. Partial prerender’s old experimental.ppr flag is gone — static shell + dynamic holes is what Cache Components does.

EraPrimitive
PagesgetStaticProps / getServerSideProps / getStaticPaths
App 13–15fetch cache, export const revalidate, unstable_cache, revalidatePath / revalidateTag
App 16cacheComponents: true, 'use cache', 'use cache: private', 'use cache: remote'
LifetimescacheLife('hours') or custom { stale, revalidate, expire }
InvalidationcacheTag + updateTag (immediate) vs revalidateTag(tag, 'max') (SWR) vs refresh() (uncached)
StoragecacheHandlers (plural) for 'use cache'; cacheHandler (singular) for ISR + images
After the responseafter() — finish work once the user already has the reply
Force request-timeconnection() — “do not prerender this”

05Routing deep cuts

File conventions that change what the URL means, not just what it looks like.

PatternUse
Parallel routes (@slot)Independent panes (dashboard + feed). Needs default.tsx when a slot has no match.
Intercepting ((.) (..) (...))Soft-nav modal; hard-nav full page.
Private folders (_lib)Not a route.
useSelectedLayoutSegment(s)Active nav without parsing the URL by hand.
useLinkStatusPending state on a <Link> (often with prefetch={false}).
useRouter / router.refresh()Client navigation + refetch RSC payload without a full reload.
Multi-zonesTwo Next apps, one domain, rewrites as the glue.
Custom servernode server.js in front of Next. Useful once so you know the cost.

07React 19 that Next already wires up

You have useTransition and useActionState (login only). The rest is unused.

APIWhy try it

11Suggested order

If you actually build things, do these five — not the whole list. New repo for 1 and 2; this repo for 3 and 5.

  1. Photo gallery Intercept + next/image + next/og + View Transitions. New repo. Most skills per hour.
  2. MDX blog + ISR + Draft Mode The job-interview set. New repo.
  3. Instant Navigations on /log and /stats Modern Next, on an app you already use every day.
  4. Pages Router clone of a tiny slice So App Router stops feeling like “just how React is.”
  5. useOffline banner on this PWA Small, timely, phone-native. This repo.
