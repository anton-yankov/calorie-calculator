Desktop Layout & UI Fixes

Two small quality-of-life fixes: stop the photo picker's placeholder text from bleeding through the "Preparing photo…" overlay, and give desktop screens a real layout instead of a phone column floating in empty space.

Branch: ui-fixes-desktop-layout Scope: 4 files, CSS/JSX only Risk: low — no state or API changes

01Scope

✓ hide placeholder during photo prep ✓ two-column analyze page on lg+ ✓ nav & log widths follow ✗ new components ✗ state/provider changes ✗ mobile layout changes

Everything is Tailwind classes plus a couple of wrapper <div>s. The mobile experience — the app's primary use case — renders exactly as before.

02Fix: placeholder shows through the prep overlay

While a HEIC photo is being decoded/resized, PhotoInput shows a translucent bg-background/75 overlay with a spinner — but the "Take or choose a photo" empty-state underneath stays visible through it.

The overlay is intentionally translucent (over an existing photo, "Change photo" prep should still show the old image). The problem is only the empty-state text competing with the spinner. So: when preparing is true and there is no previewUrl, make the placeholder content invisible — it keeps its layout size (no frame jump when prep finishes) but nothing renders behind the loader.

Why invisible and not conditional rendering: the placeholder defines the frame's height. Removing it would collapse the frame to the overlay's height, then pop when the preview arrives.

03Desktop: two-column analyze page

Today every page is one max-w-2xl (672px) column. On a 1440px screen that's less than half the viewport doing work. The analyze page has a natural split: controls (photo, description, button) and results (the estimate thread).

How the single-column markup becomes a grid

The page's children already group cleanly. Wrap them in two containers whose stacking order matches today's mobile order, so the grid costs nothing on small screens:

<main class="... max-w-2xl lg:max-w-5xl lg:grid lg:grid-cols-[2fr_3fr] lg:items-start lg:gap-x-10">
  <header class="lg:col-span-2">…</header>
  <div class="flex flex-col gap-4 lg:sticky lg:top-24">   {/* photo, description, analyze, error */}
  <section class="flex min-w-0 flex-col gap-4">           {/* thread, skeletons, log + correction */}
